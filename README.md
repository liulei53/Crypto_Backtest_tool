📘 README — 潜力区币回测工具

#### 🧭 工具简介

潜力区币回测工具 是一个基于网页的可视化分析工具，
用于训练交易盘感、验证潜力区币的表现，并回测不同止盈方式的效果。
通过设置发布时间与兜底/探顶价格，用户可以在历史行情中模拟实盘决策，
直观观察后续走势与策略表现。

#### ⚙️ 主要功能
**（1）设置发布时间**

选择任意历史时点，模拟你在那个时间点发布或关注某个币种的场景。

**（2）设置兜底/探顶价格**

标记价格区间，用于验证后续行情中价格是否触及、反转或突破。

**（3）K线图与指标展示**

	1. 币安实时 K 线数据
	2. MA5 / MA10 / MA20 / MA60 均线系统
	3. BOLL 布林带轨道
	4. 所有指标可一键隐藏/显示，专注观察关键结构
	5. 盘感训练与策略验证
**（4）用户可通过回放历史走势，练习判断潜力区的买入时机、
评估止盈止损策略的胜率与盈亏比。**

	1. 历史记录管理
	2. 自动保存查询历史
	3. 支持筛选、导出与导入
	4. 便于长期积累盘感与策略验证数据

#### 🚀 工具用途

该工具旨在帮助用户：

 	 1.	复盘历史行情，训练对趋势启动与拐点的直觉判断；
     2.	回测不同止盈、止损、持仓策略的效果；
     3.	探索潜力区币的波动特征与阶段性规律；
     4.	在不接触真实资金的前提下，强化实盘思维。
